# Repository contribution instructions

- Every commit created by an AI assistant must begin with the assistant/model name in square brackets.
- Commits created by ChatGPT or Codex use the exact prefix `[chatGPT]`.
- If another model creates the commit, replace the prefix with that model's name, for example `[DeepSeek]`.
- Human-authored commits do not require an AI prefix unless the human explicitly requests one.
