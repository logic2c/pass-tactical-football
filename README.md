# PASS 网页原型

PASS 是一款在 8×8 棋盘上进行的足球卡牌策略游戏。本仓库包含可玩的人机对战网页原型：玩家选择控制一名球员，其余 5 名球员由 AI 控制。

## 当前实现

- 固定回合顺序：R1、B1、B2、R2、R3、B3。
- e1 与 e8 是单格球门，率先取得 3 球获胜。
- 60 张行动卡：Rock、Bishop、Knight 各 20 张。
- 6 张 Tackle 特殊卡；特殊卡分类已预留其他效果的扩展位置。
- 每回合自动抽 2 张，然后可以连续出牌；也可以跳过出牌阶段再抽 2 张。
- 传球改为公开落点球，没有响应阶段和完成后的中途拦截。
- 取消越位，持球移动进入球门或传球进入球门都会得分。
- AI 按局面收益加权随机选择，不会每局执行完全相同的行动。
- 牌库用完后会自动洗入弃牌堆。

完整规则见 [RULES.md](./RULES.md)。

## 配置并启动游戏

当前版本是单机人机对战测试版，不需要网页服务器或账号系统。

### 1. 安装运行环境

需要 Node.js 22.13 或更高版本、pnpm，以及下载项目时可选的 Git。

```text
node --version
npm install --global pnpm
pnpm --version
```

### 2. 下载项目

可以在 GitHub 仓库点击 **Code → Download ZIP**，或者使用：

```text
git clone https://github.com/logic2c/pass-tactical-football.git
cd pass-tactical-football
```

### 3. 安装并启动

```text
pnpm install
pnpm dev
```

在浏览器打开终端显示的地址，通常是 `http://localhost:3000`。按 `Ctrl + C` 停止。

生产构建可以使用：

```text
pnpm build
pnpm start
```

## 游戏内配置

1. 开始时选择由你控制的一名红队或蓝队球员，开赛后不能更换。
2. 点击己方半场空格调整自己球员的位置；其余 5 名 AI 使用默认阵型。
3. 点击“开始比赛”。进球后可以再次调整自己的位置并确认开球。
4. 顶部黄色标记显示当前球员，`YOU`/`AI` 表示控制者，球员旁的 `●` 表示公开持球者。
5. 足球传到空格后会单独显示在棋盘上，直到某名球员移动经过该格。

## 每回合怎样操作

回合开始会自动抽 2 张牌。出牌阶段尚未使用任何牌时，可以点击“蓄力”跳过出牌并再抽 2 张。

- **MOVE**：选择行动卡和 MOVE，再点击高亮位置。只要仍满足持球限制，就可以继续使用其他牌。
- **PASS**：只有持球者可用。选择行动卡和 PASS，再点击该属性能够到达且没有对方球员挡住线路的空格。传球后立即弃牌并结束回合。
- **TACKLE**：选择 Tackle 特殊卡，再点击任意有手牌的对方球员。每回合最多一次，随机抽中足球时立即获得球权。
- **结束出牌**：保留当前状态，直接进入弃牌阶段。

行动卡路线：

- Rock：横纵移动或传球。进攻方 Move 最多 3 格，防守方不限；Pass 不限距离。
- Bishop：斜线移动或传球。进攻方 Move 最多 3 格，防守方不限；Pass 不限距离。
- Knight：日字移动或传球。中间的第一格与落点都属于移动经过路线。

## 持球限制与得分

- 回合开始时已经持球：Pass 前最多再使用 1 张移动卡或特殊卡。
- 回合中途通过移动或抢断获得足球：接下来只能 Pass 或结束出牌阶段。
- 传到普通空格后，足球暂时无人持有；第一个移动经过该格的球员获得足球。
- 传球线路中间有对方球员时，该目标不能选择；传球完成后不会再触发拦截或其他玩家响应。
- 足球移动或传入对方球门都会立即得分，没有越位。

## 手牌与隐藏信息

- 进攻方手牌上限为 5，防守方为 6，只在该玩家自己的弃牌阶段检查。
- 足球、行动卡和特殊卡都计算手牌数量；足球不能弃置。
- AI 手牌以牌背显示，足球具体位于哪张未知牌不会公开，但持球者是谁始终公开。
