# PASS

> 一张牌决定跑位，一条传球线改变整场攻防。

PASS 是一款将足球、棋盘走位与手牌管理结合在一起的回合制策略游戏。你指挥场上的球员，用不同路线的卡牌完成移动、接应和传球，在对手封死线路前创造射门机会。

比赛没有复杂的操作要求，却处处需要判断：应该让持球者继续推进，还是把球送往无人区域？是消耗手牌逼抢，还是保存资源等待下一次进攻？球员的位置、行动顺序和双方仍有多少牌，都会改变一次看似简单的选择。

当前版本提供网页联机测试和 Windows 单机人机对战。

## 游戏特色

- **足球与棋盘策略结合：** 球员按照 Rock、Bishop 和 Knight 三种路线行动，传球线路同样遵循对应的几何规则。
- **无球跑位同样重要：** 传球可以直接交给队友，也可以送到空格；第一名合法经过落点的球员将获得足球。
- **手牌就是体力与战术资源：** 移动、传球和上抢都需要付出手牌，连续推进可能换来机会，也可能让球队在下一轮失去应对能力。
- **公开球权，隐藏信息：** 所有人都知道谁在持球，但不会知道足球具体藏在持球者的哪张未知手牌中。
- **单机与联机两种体验：** 在单机版中控制整支球队迎战 AI，或进入网页版与其他玩家组队和对抗。

## 基础规则

- 比赛在 8×10 棋盘上进行，双方各有 3 名球员，按照 R1、B1、R2、B2、R3、B3 的顺序交替行动。
- 每回合自动抽 1 张牌。无球队员获得 2 点行动力，持球者获得 1 点；当前每张行动卡消耗 1 点行动力。
- Rock 可以横向或纵向移动最多 3 格，Bishop 可以斜向移动最多 2 格，Knight 按国际象棋的“日”字路线移动。球员不能穿过任何人。
- 持球者可以消耗行动卡传球。Rock 最多传 6 格，Bishop 最多传 4 格，Knight 使用一次标准“日”字路线；任何球员都能阻挡线路，最先挡路的队友可以直接接球。
- 传到空格的足球会留在场上，第一名沿合法移动路线经过该格的球员获得球权。
- 防守方可以消耗 1 点行动力并弃置一张牌，对一格以内的持球者上抢。
- 球门位于棋盘两端 D、E 线外侧。球员不能进入球门，必须通过合法传球线路完成射门；率先攻入 3 球的一方获胜。

禁区、手牌上限、重新开球、联机控制方式等完整规则见 [RULES.md](./RULES.md)。

## Windows 单机版

Windows 单机版由玩家控制一整支球队，对方球队由 AI 控制。构建完成后的 `.exe` 可以直接发给朋友，对方无需安装 Node.js、pnpm 或配置 GitHub。

### 构建环境

- Windows 10 或 Windows 11（64 位）
- Git
- Node.js 22.13 或更高版本
- pnpm

当前 GitHub Releases 尚未提供预先打包的安装文件，需要先在 Windows 电脑上自行构建一次。

### 下载并配置项目

在 PowerShell 中进入准备存放游戏的磁盘和文件夹，然后执行：

```powershell
git clone https://github.com/logic2c/pass-tactical-football.git
Set-Location pass-tactical-football
corepack enable
corepack prepare pnpm@latest --activate
pnpm install
```

如果项目已经下载，只需进入项目文件夹并执行 `pnpm install`。

### 生成 Windows 单机版

```powershell
pnpm desktop:dist
```

完成后，可运行文件位于项目的 `release` 文件夹中，文件名类似：

```text
PASS-0.1.0-Windows.exe
```

双击即可启动。首次运行时，如果 Windows 显示来源保护提示，选择“更多信息”，再选择“仍要运行”。游戏中按 `F1` 可以打开内置文字教程。

### 更新后重新构建

```powershell
git pull
pnpm install
pnpm desktop:dist
```

新的可运行文件仍会生成在 `release` 文件夹中。

更详细的桌面版说明见 [DESKTOP.md](./DESKTOP.md)。
