# PASS 网页原型

PASS 是一款在 8×8 棋盘上进行的足球卡牌策略游戏。本仓库包含第一版可玩网页原型，适合一名测试者在同一台设备上控制红蓝两队共 6 名球员。

## 当前实现

- 固定回合顺序：R1、B1、B2、R2、R3、B3。
- e1 与 e8 是单格球门，率先取得 3 球获胜。
- 60 张行动牌：Rock、Bishop、Knight 各 20 张。
- 包含布阵、移动、抽牌、抢断、Pass 两阶段响应、路线拦截、攻防转换、越位、手牌上限和重新开球。
- 牌库用完后会自动洗入弃牌堆。

完整规则见 [RULES.md](./RULES.md)。

## 游玩方式

当前版本是单机同屏测试版，不包含机器人或真正的网络联机。其他人可以克隆本仓库并在自己的浏览器中运行。

需要 Node.js 22.13 或更高版本，以及 pnpm：

```text
pnpm install
pnpm dev
```

启动后打开终端中显示的本地网址，通常为 `http://localhost:3000`。

## 验证

```text
pnpm test
pnpm lint
```

`pnpm test` 会生成生产构建，并执行页面渲染、移动范围、球门可达性和 Knight 拦截路径回归测试。
