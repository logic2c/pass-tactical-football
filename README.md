# PASS 网页原型

PASS 是一款在 8×8 棋盘上进行的足球卡牌策略游戏。本仓库包含可玩的人机对战网页原型：玩家选择控制一名球员，其余 5 名球员由 AI 控制。

## 当前实现

- 固定交替回合顺序：R1、B1、R2、B2、R3、B3。
- e1 与 e8 是单格球门，率先取得 3 球获胜。
- 52 张牌：Rock、Bishop、Knight 各 13 张，另有 13 张特殊卡。
- 特殊卡包括 Tackle、冲刺、补给、长传、扑救和飞踢。
- 每回合自动抽 1 张；随后在准备阶段，无球队员获得 2 点行动力，持球者获得 1 点。
- 卡牌右上角标出行动力费用，当前同时存在 0 费与 1 费卡。
- 防守方可以近身无卡上抢；Tackle 改为攻防双方都能使用。
- Pass 宣布后，符合条件的防守球员可以用扑救响应。
- 棋盘上方会即时显示最近一次行动，路径、目标和球权变化也会短暂高亮。
- 普通 Pass 可以射门；长传不能传入球门。Pass 时若已有进攻球员位于对方球门格，则判越位并交换球权。
- AI 按局面收益加权随机选择，不会每局执行完全相同的行动。

完整规则见 [RULES.md](./RULES.md)。

## 配置并启动游戏

当前版本是单机人机对战测试版，不需要网页服务器或账号系统。

需要 Node.js 22.13 或更高版本和 pnpm。可以在 GitHub 点击 **Code → Download ZIP**，也可以运行：

```text
git clone https://github.com/logic2c/pass-tactical-football.git
cd pass-tactical-football
pnpm install
pnpm dev
```

在浏览器打开终端显示的地址，通常是 `http://localhost:3000`。生产构建可以使用：

```text
pnpm build
pnpm start
```

## 游戏内配置

1. 开始时选择由你控制的一名红队或蓝队球员，开赛后不能更换。
2. 点击己方半场空格调整自己球员的位置；其余 5 名 AI 使用默认阵型。
3. 点击“开始比赛”。进球后可以再次调整自己的位置并确认开球。
4. 顶部黄色标记显示当前球员，球员旁的 `●` 表示公开持球者。
5. 棋盘上方的行动提示会显示谁做了什么以及公开结果，无需反复翻阅比赛记录。
6. 足球传到空格后会单独显示，直到某名球员合法移动经过该格；直接传给队友则立即由队友持球。

## 每回合怎样操作

回合开始自动抽 1 张，随后进入准备阶段并获得行动力。尚未行动时可以点击“蓄力”，跳过出牌并额外抽 2 张。

- 无球队员获得 2 点行动力，持球者获得 1 点；飞踢减益在准备阶段结算。
- **MOVE**：选择移动卡和 MOVE，再点击高亮位置，支付卡面费用 1。
- **PASS**：只有持球者可用。选择移动卡和 PASS，再点击合法空格或队友；扑救响应结算后进入弃牌阶段。
- **PRESS**：防守方无需卡牌即可上抢王的一格以内的对手。只有抽中足球才会拿走，否则放回；每回合最多一次。
- **TACKLE**：双方均可使用；选择一格以内的对手并随机抢走一张牌，每回合最多一次。
- **冲刺（0）**：本回合获得 1 点额外行动力。
- **补给（1）**：抽 2 张牌，抽到的牌可以立即使用。
- **长传（0）**：令本回合下一次 Pass 可以越过第一名球员，但不能越过第二名球员，也不能射门。
- **扑救**：防守方在对手宣布 Pass 后响应；弃 X 张额外牌移动 X 步。进攻方可 0 费弃置扑救并抽 1 张。
- **飞踢（1）**：对“一步”内的对手使用，使其下回合行动力 −1；若其持球则直接夺球。
- **结束出牌**：保留当前状态，直接进入弃牌阶段。

回合中途获得足球不会重置行动次数：第一次行动拿到球通常还剩 1 次，可移动或传球；第二次行动拿到球时剩余 0 次，不能继续行动。下一回合若仍持球，则以持球者的 1 次行动开始。

## 路线规则

- Rock：横纵 Move 最多 3 格；Pass 不限距离。
- Bishop：斜线 Move 最多 3 格；Pass 不限距离。
- Knight：日字移动或传球。
- Move 不能穿过队友或对手；Knight 的第一格也不能被占据。
- Pass 路线会被任何球员阻挡；最先挡路的队友可以作为直接接球目标，对手不能成为传球目标。
- Knight 的第一格路线若是队友，可直接把球传给该队友；若是对手，则后续落点均被阻挡。
- “一步”仅指横向或纵向相邻；“一格”包括横向、纵向和斜向相邻。
- 长传可以越过线路上的第一名球员，第二名球员仍会封锁线路。
- 移动合法经过落地足球时会拾球；足球本身不会阻挡路线。

## 手牌与隐藏信息

- 进攻方行动卡与特殊卡上限为 5，防守方为 6，只在自己的弃牌阶段检查。
- 足球不计入上限且不能弃置。
- AI 手牌以牌背显示，足球具体位于哪张未知牌不会公开，但持球者始终公开。

## 行动轨迹

- 每次 Move 用实线箭头表示；同一回合移动两次会保留两道箭头。
- Pass 用虚线箭头表示。
- 扑救移动使用独立的黄色响应轨迹，不会覆盖球员自己的回合记录。
- 每名球员的轨迹保留到其下次回合开始；进球重新布阵时清空全部旧轨迹。
