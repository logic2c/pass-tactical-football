# PASS 网页原型

PASS 是一款在 8×8 棋盘上进行的足球卡牌策略游戏。本仓库包含可玩的人机对战网页原型：玩家选择控制一名球员，其余 5 名球员由 AI 控制。

## 当前实现

- 固定回合顺序：R1、B1、B2、R2、R3、B3。
- e1 与 e8 是单格球门，率先取得 3 球获胜。
- 60 张行动牌：Rock、Bishop、Knight 各 20 张。
- 包含布阵、移动、抽牌、抢断、Pass 两阶段响应、路线拦截、攻防转换、越位、手牌上限和重新开球。
- AI 会综合持球推进、传球与射门线路、拦截风险、抢断概率和手牌余量进行收益评分，再按权重随机选择行动；高收益方案更常出现，但不会每局完全相同。
- 牌库用完后会自动洗入弃牌堆。

完整规则见 [RULES.md](./RULES.md)。

## 配置并启动游戏

当前版本是单机人机对战测试版：一名玩家控制所选球员，其余 5 人由 AI 自动操作。它尚不包含真正的网络联机，但任何人都可以在自己的电脑上运行。

### 1. 安装运行环境

需要：

- [Node.js](https://nodejs.org/) 22.13 或更高版本。
- [pnpm](https://pnpm.io/installation/) 包管理器。
- Git（只有使用 `git clone` 下载时需要）。

安装 Node.js 后，可以在 PowerShell、终端或命令提示符中检查版本并安装 pnpm：

```text
node --version
npm install --global pnpm
pnpm --version
```

### 2. 下载项目

方法一：在 GitHub 仓库页面点击 **Code → Download ZIP**，下载并解压，然后在解压后的文件夹中打开终端。

方法二：使用 Git 克隆：

```text
git clone https://github.com/logic2c/pass-tactical-football.git
cd pass-tactical-football
```

### 3. 安装依赖并启动

在项目根目录执行：

```text
pnpm install
pnpm dev
```

终端显示启动成功后，在浏览器打开它给出的地址，通常是：

```text
http://localhost:3000
```

停止游戏服务器时，在终端按 `Ctrl + C`。

如果要测试生产构建：

```text
pnpm build
pnpm start
```

## 游戏内配置

1. 页面打开后首先进入“选择角色并布阵”。红蓝双方各有 3 名球员。
2. 在右侧选择你要控制的一名红队或蓝队球员；开赛后不能更换。
3. 点击自己的球员，再点击其己方半场内的空格调整位置。其余 5 名 AI 使用默认阵型。
4. 球员不能放在已有球员或球门所在格。需要恢复初始位置时点击“默认阵型”。
5. 准备好后点击“开始比赛”。之后每次进球或越位重开时，也可以重新调整自己的位置并点击“确认开球”。
6. 回合固定按 `R1 → B1 → B2 → R2 → R3 → B3` 循环。顶部黄色标记显示当前行动球员，`YOU`/`AI` 表示控制者，`●` 表示足球持有者。

## 每回合怎样操作

轮到一名球员时，可以选择“抽牌”，或先点击底部的一张行动牌，再选择一个行动：

- **抽牌**：进攻方抽 2 张，防守方抽 3 张，然后立即结束回合。
- **MOVE**：按所选卡牌的 Rock、Bishop 或 Knight 属性移动。点击棋盘上的高亮空格完成行动。
- **TACKLE**：仅防守方可用。选择行动牌和 TACKLE 后，点击任意拥有手牌的对方球员，随机抽取其一张暗牌；抽到足球就会立即交换攻防。
- **PASS**：仅进攻方可用，但不要求发起者持有足球。选择行动牌和 PASS，再选择至少一张要倒扣传递的手牌，点击“发起 Pass”。倒扣组合可以包含足球，也可以只是佯攻。

行动牌属性对应的路线：

- **Rock（横纵）**：进攻方 Move 最多 3 格；防守方 Move 不限距离；Pass 不限距离。
- **Bishop（斜线）**：进攻方 Move 最多 3 格；防守方 Move 不限距离；Pass 不限距离。
- **Knight（走日）**：双方均按日字移动。Knight Pass 的第一格如果站有防守者，会被拦截。

## PASS 响应流程

发起 PASS 后，除传球者外的其他 5 名球员依照回合顺序逐一响应。每名响应者都有两个可选步骤：

1. **按牌移动**：选择一张行动牌，再点击高亮位置；不想移动可点击“跳过第 1 步”。
2. **弃牌冲刺**：选择任意数量行动牌，再点击与弃牌数相同距离的横纵位置；不想冲刺可直接点击“完成响应”。

两步可以都执行、只执行一步或全部跳过。所有人完成响应后：

- 点击高亮队友完成传球。
- 若倒扣组合包含足球，并且对方球门符合所用卡牌路线，可以点击球门射门。
- 如果路线被防守者拦截，按页面提示从揭开的组合中选择一张截获牌。
- 如果场上没有合法目标，游戏会自动进入传球失败的揭牌处理，不需要手动跳过。

## 手牌、越位和胜负

- 进攻方手牌上限为 5，防守方为 6；只在该球员自己的回合结束时检查。
- 手牌超限时，点击行动牌弃置到上限。足球不能弃置。
- 不能使用 MOVE 或响应移动把足球带入对方球门；这样会触发越位、交换球权并重新开球。
- 只有通过 PASS 把足球送入对方球门才会得分。
- 率先取得 3 球的一方获胜。
- 右侧比赛记录按最新在前显示每一步结算；右上角“重开比赛”会清空当前对局。

AI 的手牌以牌背显示，只有你控制球员的手牌可以操作；足球位置仍在棋盘上公开显示。完整规则和特殊情况见 [RULES.md](./RULES.md)。
