# PASS v0.3.0 — 十行球场与全队指挥

> 发布日期：2026-07-29  
> 类型：场地扩展、单机控制与基础行动调整

## 8×10 球场

- 球场由 8×8 扩展为 8列×10行。
- 横轴继续使用 `a–h`；纵轴依次使用 `1–9、X`，其中 `X` 表示第10行，所以坐标始终保持两个字符。
- 两端禁区调整为 `c1–f1` 与 `cX–fX`，双格场外球门仍位于 D、E 两列之外。
- 中线位于第5、6行之间。禁区犯规后，红方从 `e5`、蓝方从 `d6` 重新开球。
- 3v3默认阵型：红方 `d2、f2、e3`；蓝方镜像为 `e9、c9、d8`。
- Rock、Bishop 与 Knight 的移动、传球距离保持 v0.2.0 数值。

## 单机改为全队操作

- 单机开局从“选择一名球员”改为选择红队或蓝队，默认红队。
- 玩家操作己方全部3名球员，对方全部3名球员由AI操作。
- 当前行动球员自动显示可操作手牌；玩家也可点击己方回合顺序标记查看其他己方球员手牌，但不能用非当前球员出牌。
- AI托管功能暂不上线。
- 网页联机仍保持每名真人只控制自己所选球员，不受本次单机控制调整影响。

## 初始防守补牌

- 防守方额外补牌现在只在比赛首次开球时触发。
- 初始防守方每名球员比初始进攻方多获得1张牌。
- 进球、禁区犯规、普通球权转换以及之后的重新开球均不再补牌。

## Press解除次数限制

- Press原有效果、目标、费用和随机结算完全不变。
- 移除“每回合最多一次”的限制；只要仍有行动力、可弃置的非足球牌，并且邻近对方持球者，就能再次使用。
- 抢到足球后使用者转为进攻方，因此不再满足Press条件。

## AI调整

- AI优先执行合法射门、拾取落地球和避免确定的禁区超员犯规。
- 持球AI会避免无意义地进入对方禁区并失去射门机会。
- 防守AI会按夺球概率和费用牌价值逐次评估Press，不再机械地只尝试一次。
- 同一战术层级内继续采用收益加权随机，保留非固定走法。

## 界面修正

- Knight卡面改为真正绘制“先向上、再向右上斜走”的两段日字路线。
- “蓄力”更名为“战术整备”。

## 体验热修复

- 修复单机整队操控时，当前球员与手牌显示慢一人的问题。每名己方球员的回合开始时会自动展示其手牌，同时仍可手动查看其他队友手牌。
- 当当前球员行动力降为 0，且手牌中没有 0 点行动力卡牌时，立即自动进入弃牌阶段；该规则同时适用于单机、AI 与联机对局。

## 新增多人控制模式

- 新增“3v3 双人整队”：房间仅需两名真人，红蓝双方各由一人控制三名球员。
- 新增“4v4 四人搭档”：每队两名真人，一人控制 1/3 号球员，另一人控制 2/4 号球员。
- 玩家可以查看自己控制的全部球员手牌，但无法查看同队另一名真人控制的手牌。
- 服务器的回合鉴权、重新连接、超时托管、AI 补位与私密手牌快照均支持一名玩家控制多个球员。
- 大屏幕手牌区改为从顶部排列的双列滚动网格，修复7张以上手牌无法查看顶部卡牌的问题。
